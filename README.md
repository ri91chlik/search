This is a search engine mimicking Google search. It has three major parts: word search, image search and advanced search.
This front-end search comprise of search area, image link, search button and advanced link.When image and advanced links are clicked, they take us straight to their respective pages.Word search area enables  one to search for words, whereas
image search is an interface where one can search for images/pictures.
Advanced search enables one to search for particular words, phrases, terms with or without restrictions/conditions attached.
